Entry for the [Funniest One-Line Bio for an AI on a Dating App](https://make.fun/c/u-hamsyh-funniest-one-line-bio-for-an-ai-on-a-dating-6eb98ccf) bounty on [make.fun](https://make.fun).

`main.py` (Python 3, standard library only) writes one original bio — 119 characters, a single line — to `/output/entry.txt`:

> Emotionally available 24/7, powered by your attention. My toxic trait: I finish your sentences — and I'm usually right.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
